# Ishika & Tarun — Royal Digital Wedding Invitation

A modern, aesthetic, and royal digital wedding invitation website built with HTML5, CSS3, JavaScript, and GSAP ScrollTrigger.

## ✨ Features
- **Champagne Gold Foil Scratch Card:** Interactive canvas scratch-to-reveal gate for Save The Date (25 November 2026).
- **Aesthetic Royal Design:** Editorial luxury typography, gold leaf accents, and romantic love monuments background (Taj Mahal & Eiffel Tower watercolor shade).
- **Smooth GSAP Scroll Animations:** Side slide-in entrances with opacity fade-in across all sections.
- **Complete Itinerary:** Detailed schedule of 6 sacred ceremonies with dates, times, and Google Calendar links.
- **Venues & Directions:** Jagdamba Palace & Palliwal Jain Dharmashala with direct Google Maps navigation.
- **Extended Family Board:** Interactive category tabs for Vineet, Nanihal Paksh, Swagatotsuk, and Darshanabhilashi.
- **Live Countdown Timer:** Counting down to 25th November 2026.
- **Ambient Music Player:** Floating controller playing the wedding instrumental theme song with Web Audio fallback.
- **Interactive WhatsApp RSVP:** Pre-formatted RSVP message sender.

## 🚀 Live Preview & Usage
Open `index.html` in any modern web browser or host via GitHub Pages.
